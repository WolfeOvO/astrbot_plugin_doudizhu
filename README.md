# 斗地主 (astrbot_plugin_doudizhu)

🃏 完整欢乐斗地主玩法，运行于 AstrBot + NapCat（QQ）。群聊内开桌，双手牌私发。

## 功能

- **完整规则**：叫分（1/2/3）→ 抢地主 → 加倍（普通×2 / 超级加倍×4）→ 出牌；单张/对子/三张/三带一/三带二/顺子/连对/飞机（带单/带对）/四带二/炸弹/王炸 全牌型
- **癞子玩法**（对齐腾讯欢乐斗地主）：
  - 癞子可代替除大小王以外的任意点数；癞子单独出只能作本身
  - 炸弹分级：王炸 > 纯癞子炸弹 > 硬炸弹 > 软炸弹
  - 倍数：软炸 ×2，硬炸/纯癞子炸 ×4，王炸 ×4（经典场王炸 ×2）
- **加倍/超级加倍**（对齐欢乐斗地主）：抢地主后每人可选 不加倍 / 加倍×2 / 超级加倍×4，超时默认不加倍
- **人机模式**：人不够时 AI 补位（1真+2机 / 2真+1机 / 纯 AI 对局）；机器人乐豆无限（∞），不入账、不上榜
- **难度分级**：新手场（AI 会犯错）/ 标准场 / 大师场（AI 更聪明，`设置斗地主 难度 简单|普通|困难`）
- **输赢封顶**：`设置斗地主 封顶 500` — 单局单人多输赢上限（0=不封顶），结算时明确提示是否触发
- **对局持久化**：插件热更新/重启不丢局，未完成的牌局自动恢复
- **结算明细**：底分 × 倍数 × 转化率 = 结算基数，每人显示增减与余额；玩家名统一【】括起
- **托管 / 取消托管**：中途接管交给 AI 代打，随时发「取消托管」收回，乐豆与战绩照常结算
- **不洗牌 / 极速场**：上桌可选「不洗牌」（点数成堆，炸弹更多）与「极速」（超时 20s）
- **群内临时会话发牌**：不用加好友，机器人每轮私发「文字 + 手牌图片」（NapCat 临时会话）
- **乐豆经济**：底分×倍数结算、每日签到（连签加成）、救济金、乐豆榜、战绩
- **超时规则**：叫分/抢/加倍超时自动弃权；出牌跟牌超时自动「不出」；先手超时自动出最小单张（想 AI 代打请用「托管」）
- **每轮私发**：轮到你出牌时，机器人私聊发送「现在的情况」= 你的手牌图片 + 手牌文字 + 需大过；托管期间暂停推送
- **播报不单调**：出牌带「身份（地主/农民）+ 剩余牌数（竖排）+ 炸弹加成」；轮到你时贴出「需大过」提示与可用指令
- **一群一局**：同一个群同一时间只能进行一场斗地主
- **群主/管理员配置**：模式、底分、超时、AI 补位、入场门槛、签到奖励

## 命令一览（唤醒前缀 `#`）

| 命令 | 说明 |
|---|---|
| `上桌 [经典\|癞子\|不洗牌\|极速]` | 加入牌桌（别名：斗地主、来一局、打牌）；不洗牌=炸弹更多💣，极速=20s超时 |
| `下桌` | 离开牌桌 |
| `开局` / `人机` / `开始` | 开局；人不齐自动 AI 补位（至少 1 人上桌即可） |
| `叫分 N` / `不叫` | 叫分阶段 |
| `抢` / `不抢` | 抢地主阶段 |
| `加倍` / `超级加倍` / `不加倍` | 加倍阶段（×2 / ×4） |
| `出 <牌>` / `不出` | 出牌（任意写法，如 `#出 ♥2`、`#出 34567`） |
| `提示` | 私聊给你出牌提示（别家看不到） |
| `我的牌` | 手动重发手牌（一般用不到，每轮会自动私发） |
| `结束` / `解散牌局` | 对局玩家或群管理结束本局（流局，不计乐豆） |
| `托管` / `取消托管` | 交由 AI 代打 / 随时收回自己打 |
| `乐豆` / `豆签到` / `救济金` / `乐豆榜` / `战绩` | 经济系统 |
| `设置斗地主 <项> <值>` | 群主/管理配置（模式/难度/底分/封顶/超时/人机/开关/门槛/签到） |
| `斗地主帮助` | 查看帮助 |

出牌写法：点数即可（`34567`、`对3`、`三个4带5`、`334455`、`小王大王`），花色可选（`♠3♥4`、`s3 h4`），智能解析。

## 部署

```bash
# 拷贝到 AstrBot 插件目录后重启（首次安装需要完整重启）
cp -r astrbot_plugin_doudizhu /opt/astrbot/data/plugins/
sudo docker restart astrbot
```

依赖：仅用容器自带的 Pillow + 文泉驿正黑字体（无需额外安装）。

## 架构

```
astrbot_plugin_doudizhu/
├── main.py          # 插件入口：命令注册 + 发送通道（群/临时会话）
├── metadata.yaml
├── _conf_schema.json
├── engine/          # 纯规则引擎（无 I/O，可独立测试）
│   ├── cards.py     # 牌模型 + 玩家输入解析
│   ├── combos.py    # 牌型识别/比较/癞子解释（软炸/硬炸/纯癞子炸）
│   ├── game.py      # 对局状态机（叫分→抢→加倍→出牌→结算）
│   └── ai.py        # AI 决策（叫分评估/出牌搜索/配合逻辑）
├── services/
│   ├── economy.py   # 乐豆 + 战绩 + 群配置（JSON 持久化）
│   ├── render.py    # PIL 手牌/结算图渲染
│   └── room.py      # 房间管理 + 流程驱动 + 定时器
└── tests/           # 引擎与对局测试（120+ 断言 + 450 局模糊测试）
```
